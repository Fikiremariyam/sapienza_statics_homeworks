Homework 7 · Modes of convergence · LLN · CLT · Bayes' theorem

How random things settle down, and how beliefs get updated

Part A compares the four main ways a sequence of random variables can converge, and shows where each one is used in the Law of Large Numbers, the Central Limit Theorem and statistical inference, including why √n keeps appearing. Part B covers conditional probability and Bayes' theorem: how a prior and a likelihood combine into a posterior, with worked examples and their strengths and weaknesses.

Part A Modes of convergence

The four modes of convergence

For ordinary numbers "aₙ → a" has one meaning. A random variable Xₙ is a function of the outcome ω, so "Xₙ → X" can mean different things depending on what we ask to become small: the deviation for each outcome, the probability of a large deviation, the average squared deviation, or only the shape of the distribution.

a.s.

Almost sure convergence

P( { ω : Xₙ(ω) → X(ω) } ) = 1

Pathwise. Fix the outcome ω and you get an ordinary sequence of numbers X₁(ω), X₂(ω), … . It converges for every ω except a set of probability zero. Equivalently, for every ε > 0, P( supm≥n |Xₘ − X| > ε ) → 0: eventually the path enters the ε-band and never leaves it again.

P

Convergence in probability

for every ε > 0: P( |Xₙ − X| > ε ) → 0

At each large n, a big deviation is unlikely. It says nothing about the same ω over time: the few outcomes with a large deviation at time n may be different outcomes at time n + 1, and one path can still jump out of the band infinitely often.

L²

Mean-square convergence

E[ (Xₙ − X)² ] → 0

The average squared error goes to zero. It needs finite second moments and measures the size of the deviations, not only how often they happen. It is the mode that variances and mean squared errors speak about: MSE = bias² + variance. (Lᵖ: E|Xₙ − X|ᵖ → 0.)

d

Convergence in distribution

Fₙ(x) = P(Xₙ ≤ x) → F(x) = P(X ≤ x) at every x where F is continuous

Only the shapes of the distributions converge. Xₙ and X need not even live on the same Ω. Equivalent forms: E[g(Xₙ)] → E[g(X)] for every bounded continuous g (Portmanteau), or characteristic functions φₙ(t) → φ(t) (Lévy's continuity theorem, the tool used to prove the CLT).

How the modes are related

The four modes are ordered by strength. The arrows below are theorems; every missing arrow has a counterexample, three of which you can see in the lab above.

Implications (proof sketches)

  • a.s. ⇒ P. If the path eventually stays within ε, then P(|Xₙ − X| > ε) ≤ P(supm≥n|Xₘ − X| > ε) → 0.
  • L² ⇒ P. Chebyshev–Markov: P(|Xₙ − X| > ε) ≤ E[(Xₙ − X)²] / ε² → 0.
  • L² ⇒ L¹. Jensen / Cauchy–Schwarz: E|Xₙ − X| ≤ √E[(Xₙ − X)²].
  • P ⇒ d. For a continuity point x: P(Xₙ ≤ x) ≤ P(X ≤ x + ε) + P(|Xₙ − X| > ε), and the symmetric bound below; let n → ∞ then ε → 0.

Counterexamples (the missing arrows)

  • P but not a.s. (also L² but not a.s.): the typewriter. Block k has k indicators of width 1/k sweeping across [0,1]. P(Xₙ ≠ 0) = 1/k → 0 and E[Xₙ²] = 1/k → 0, yet every ω is hit once in every block, so Xₙ(ω) = 1 infinitely often.
  • a.s. but not L²: Xₙ = n·1{U < 1/n}. For each U > 0 the path is 0 once n > 1/U, but E[Xₙ²] = n² · (1/n) = n → ∞.
  • d but not P: X ~ N(0,1) and Xₙ = −X. Same distribution for every n, but |Xₙ − X| = 2|X| never shrinks.

Partial converses that statisticians use all the time

  • d to a constant ⇒ P. If Xₙ →d c (a constant), then Xₙ →P c. This is why "consistency" can be checked through distributions.
  • P ⇒ a.s. along a subsequence (via Borel–Cantelli). If Σₙ P(|Xₙ − X| > ε) < ∞ for every ε, then Xₙ → X a.s.
  • P + uniform integrability ⇒ L¹ (Vitali); dominated convergence is the special case |Xₙ| ≤ Y with E[Y] < ∞.
  • Continuous mapping theorem. If Xₙ → X in any of a.s., P or d, then g(Xₙ) → g(X) in the same mode for continuous g.
  • Slutsky's theorem. If Xₙ →d X and Yₙ →P c, then Xₙ + Yₙ →d X + c and XₙYₙ →d cX. It is what lets us replace the unknown σ by the sample s in a test statistic.

Law of Large Numbers: convergence to a constant

The LLN says the sample mean settles at the true mean. The weak and strong laws state the same limit in two different modes.

Weak LLN: in probability (and in L²)

X₁, X₂, … uncorrelated, E[Xᵢ] = μ, Var(Xᵢ) = σ² < ∞ E[(X̄ₙ − μ)²] = Var(X̄ₙ) = σ²/n → 0 (L²) P(|X̄ₙ − μ| > ε) ≤ σ² / (n ε²) → 0 (P)

The proof is just "variance is additive, then Chebyshev", so the weak law follows from L² convergence. Khinchin's version needs only iid with E|X| < ∞ (no variance).

Strong LLN: almost surely

X₁, X₂, … iid with E|X₁| < ∞ ⟺ X̄ₙ → μ a.s. (Kolmogorov; Etemadi: pairwise independence suffices)

With probability one, the whole path of running means converges. This is what justifies reading probability as long-run frequency: the fraction of times event A occurs converges a.s. to P(A) (Borel's law), and Monte Carlo estimates converge for almost every run.

Central Limit Theorem: convergence in distribution

The LLN tells us X̄ₙ − μ → 0. The CLT zooms in on that vanishing error: multiplied by √n it does not vanish and does not explode, and its distribution becomes normal, whatever the shape of the original distribution, as long as the variance is finite.

Lindeberg–Lévy: X₁, X₂, … iid, E[X] = μ, 0 < σ² < ∞ Zₙ = √n (X̄ₙ − μ) / σ = (Sₙ − nμ) / (σ√n) →d N(0, 1) Berry–Esseen (if E|X−μ|³ = ρ < ∞): supₓ | P(Zₙ ≤ x) − Φ(x) | ≤ 0.4748 · ρ / (σ³ √n)

Why only "in distribution"?

Zₙ does not converge in probability to any random variable. Z₂ₙ and Zₙ share half their data, so Corr(Zₙ, Z₂ₙ) = 1/√2 and Var(Z₂ₙ − Zₙ) = 2 − √2 ≈ 0.59 for every n: the values keep moving, only their histogram stabilises. The CLT is a statement about the law of Zₙ, which is exactly what we need to compute probabilities, p-values and confidence intervals.

LLN and CLT together

X̄ₙ = μ + (σ/√n) · Zₙ, Zₙ ≈ N(0,1)

The LLN says the second term goes to 0 (a.s., P, L²). The CLT says how fast (like 1/√n) and with what shape (normal). Extensions: Lindeberg–Feller (non-identical summands), the multivariate CLT, martingale CLTs, and the delta method √n(g(X̄ₙ) − g(μ)) →d N(0, g′(μ)²σ²).

Why √n? Additivity of variance and independence

The square root comes straight from one identity: the variance of a sum.

Var(X₁ + … + Xₙ) = Σᵢ Var(Xᵢ) + 2 Σ_{i<j} Cov(Xᵢ, Xⱼ) If the Xᵢ are independent (uncorrelated is enough), every covariance is 0: Var(Sₙ) = n σ² ⇒ SD(Sₙ) = σ √n Var(X̄ₙ) = σ² / n ⇒ SD(X̄ₙ) = σ / √n (the "standard error")

Intuition: errors partly cancel

If n errors of size σ all pointed the same way, the sum would have size nσ. Independent errors point in random directions and partly cancel, so the total grows only like σ√n. Geometrically, centred uncorrelated variables are orthogonal vectors in L², so their lengths add like Pythagoras: ‖e₁ + … + eₙ‖ = √(‖e₁‖² + … + ‖eₙ‖²) = σ√n. That is the random walk: after n steps of ±1 you are typically about √n from the start, not n.

√n is the only scaling that gives a real limit

Var( (Sₙ − nμ) / n^α ) = σ² · n^(1 − 2α) α > ½ → 0 collapses to a point (LLN, α = 1) α = ½ → σ² stable, non-trivial (CLT) α < ½ → ∞ blows up

Dividing by n is "too much" (the limit is the constant μ); dividing by less than √n is "too little". √n is the exact balance.

When independence fails

With positive correlation the covariance terms no longer vanish. For a stationary sequence with autocorrelation ρₖ = Corr(Xᵢ, Xᵢ₊ₖ):

Var(X̄ₙ) = (σ²/n) · [ 1 + 2 Σₖ₌₁ⁿ⁻¹ (1 − k/n) ρₖ ] AR(1) with ρₖ = ρᵏ: Var(X̄ₙ) ≈ (σ²/n) · (1 + ρ)/(1 − ρ), n_eff = n (1 − ρ)/(1 + ρ)
  • Weak dependence (correlations die out fast): the rate is still 1/√n, but with a bigger constant. You effectively have only n_eff independent observations.
  • Perfect dependence (ρ = 1, every Xᵢ is the same value): Var(X̄ₙ) = σ². Averaging gives no benefit at all, and √n disappears.
  • Long-range dependence (ρₖ ~ k^(2H−2), H > ½): SD(X̄ₙ) ~ n^(H−1), slower than 1/√n. Network traffic is a classic example.
  • Infinite variance (heavy tails, α-stable laws): the right scaling is n^(1/α) instead of √n. For the Cauchy (α = 1) X̄ₙ never shrinks at all.

√n in everyday inference

  • Standard error: SE(X̄) = σ/√n, estimated by s/√n.
  • Confidence interval: x̄ ± zα/2 · s/√n.
  • Sample size: for margin E you need n = (z σ / E)². Halving the margin needs four times the data; one extra decimal digit needs 100 times.
  • Test statistic: z = √n (x̄ − μ₀)/s. With huge n, tiny effects become "significant", which is why effect size matters.
  • √n-consistent estimators: the usual parametric rate; nonparametric estimators are slower (e.g. n^(2/5) for kernel densities).

Independence is an assumption to check

Every s/√n above assumes independent (or at least uncorrelated) observations. Logs from the same host, repeated measurements on the same user, or a time series of network traffic are usually positively correlated. Using s/√n then underestimates the true uncertainty: intervals are too narrow and p-values too small. Remedies include using n_eff, block bootstrap, robust (HAC / Newey–West) standard errors, or clustered standard errors.

Part B Conditional probability and Bayes

Conditional probability

P(A | B) = P(A ∩ B) / P(B), P(B) > 0

Conditioning on B means: we have learned that B happened, so we throw away every outcome outside B and rescale what is left so it again has total probability 1. Three rules follow directly:

Multiplication rule: P(A ∩ B) = P(A | B) · P(B) = P(B | A) · P(A) Law of total probability: P(B) = Σᵢ P(B | Aᵢ) · P(Aᵢ) for a partition A₁, …, Aₖ of Ω Independence: P(A | B) = P(A) ⟺ P(A ∩ B) = P(A) · P(B)

In probability theory

  • It builds joint models step by step (chains, trees, Markov chains: P(Xₙ₊₁ | Xₙ)).
  • Conditional expectation E[X | Y] is the best prediction of X from Y in mean square. It is the orthogonal projection of X onto the functions of Y in L², the same L² geometry as in Part A.
  • Conditional independence: X₁, …, Xₙ can be dependent, but independent once θ is known. "iid given θ" is the standard Bayesian model (de Finetti's theorem).

In statistics

  • Frequentist statements condition on the parameter: P(data | θ). A p-value is P(result this extreme | H₀).
  • Bayesian statements condition on the data: P(θ | data).
  • The two are not the same: P(A | B) ≠ P(B | A) in general. Confusing them is the prosecutor's fallacy (or the base-rate fallacy, see Example 1). A p-value is not the probability that H₀ is true.

Bayes' theorem and the three components

Bayes' theorem is the multiplication rule written both ways and solved for the "reversed" conditional:

Events: P(Aⱼ | B) = P(B | Aⱼ) P(Aⱼ) / Σᵢ P(B | Aᵢ) P(Aᵢ) Parameters: π(θ | x) = f(x | θ) · π(θ) / m(x), m(x) = ∫ f(x | θ) π(θ) dθ posterior ∝ likelihood × prior Odds form: P(H₁|x) / P(H₀|x) = [ f(x|H₁) / f(x|H₀) ] × P(H₁) / P(H₀) posterior odds = Bayes factor × prior odds
ComponentWhat it isKey points
Prior π(θ)A probability distribution for the unknown θ before seeing the data.Encodes earlier studies, expert knowledge or physical constraints. Can be informative, weakly informative, "non-informative" (flat, Jeffreys π ∝ √I(θ)), or conjugate for convenience.

Why updating is central

  • Coherence: processing data in batches or all at once gives the same posterior (for conditionally iid data), because the likelihoods simply multiply: π(θ | x₁, x₂) ∝ f(x₂|θ) · [f(x₁|θ) π(θ)].
  • Direct answers: "there is a 95% probability that θ lies in [a, b], given the data" is a valid statement about a credible interval, unlike a frequentist confidence interval.
  • Decisions: choose the action that minimises posterior expected loss (Bayes rule). Squared loss → posterior mean, absolute loss → posterior median.
  • Online learning: spam filters, fraud and intrusion detectors and Kalman filters all update a posterior as each new observation arrives.

The link back to Part A

The Bernstein–von Mises theorem: under regularity conditions, as n → ∞

π(θ | x₁,…,xₙ) ≈ N( θ_MLE , I(θ)⁻¹ / n )

The posterior concentrates around the truth at the same 1/√n rate, the influence of any reasonable prior vanishes, and Bayesian credible intervals and frequentist confidence intervals become numerically the same. Posterior consistency is itself an LLN-type statement.

Worked examples

Example 1 · An intrusion-detection alarm (the base-rate effect)

A detector raises an alarm A. Let H = "the connection is an attack". The prior is the base rate P(H). The likelihood is how probable an alarm is under each hypothesis: sensitivity P(A | H) and false-alarm rate P(A | not H) = 1 − specificity. Bayes gives the posterior P(H | A), the number an analyst actually needs.

Discussion. With the default numbers, a 99%-sensitive detector gives only about a 17% chance of attack per alarm, because benign traffic is 99 times more common and 5% of it triggers false alarms. The prior dominates when the event is rare. A second independent alarm turns the 17% posterior into the new prior and pushes the posterior to about 80%: sequential updating. Limitations: the base rate is often poorly known, and the two detectors must really be conditionally independent given H, or the second alarm adds less than this calculation claims.

Example 2 · Estimating a probability: the Beta–Binomial model

In a phishing simulation, k of n employees click the link. θ is the click probability. The likelihood is binomial, L(θ) ∝ θᵏ(1 − θ)ⁿ⁻ᵏ. With a Beta(a, b) prior, π(θ) ∝ θᵃ⁻¹(1 − θ)ᵇ⁻¹, the product has the same form, so the posterior is again a Beta (a conjugate prior):

posterior: θ | k ~ Beta(a + k, b + n − k) E[θ | k] = (a + k)/(a + b + n) = w · a/(a + b) + (1 − w) · k/n, w = (a + b)/(a + b + n) posterior mean = prior mean (weight w) + MLE (weight 1 − w)

The prior acts like a + b "pseudo-observations" (a clicks, b non-clicks). The posterior mean is a compromise between the prior mean and the data, and the data win as n grows.

Discussion. The animation simulates employees with a true click rate of 0.15, one at a time, using each posterior as the next prior. The posterior narrows roughly like √(θ(1 − θ)/n), the same √n as in Part A. Advantages: a closed-form answer, an intuitive "pseudo-count" reading of the prior, and sensible estimates with small n (with k = 0 the MLE says 0%, the posterior does not). Limitation: a Beta prior has one peak; real prior knowledge may not fit that shape.

Example 3 · A continuous parameter: Normal–Normal model

We estimate the mean response time μ of a server (ms). Each measurement is Xᵢ ~ N(μ, σ²) with known σ = 30 ms; the prior from last month's monitoring is μ ~ N(μ₀ = 100, τ₀²). Precisions (1/variance) add:

1/τₙ² = 1/τ₀² + n/σ² posterior precision = prior + data μₙ = τₙ² · ( μ₀/τ₀² + n x̄/σ² ) precision-weighted average μ | x ~ N(μₙ, τₙ²) as n → ∞: μₙ → x̄, τₙ ≈ σ/√n

Discussion. With τ₀ = 20, n = 9 and x̄ = 120, the posterior is N(116, 8.94²): the prior pulls the estimate 4 ms towards 100 and makes it a little more precise than the data alone (σ/√n = 10). A very confident prior (small τ₀) can dominate a small data set; a vague prior (large τ₀) gives essentially the frequentist answer x̄ ± 1.96σ/√n.

Advantages of the Bayesian approach

  • Uses prior knowledge formally and transparently, instead of ignoring it.
  • Gives direct probability statements about parameters and hypotheses.
  • Coherent sequential updating, natural for streaming data.
  • Works with small samples and avoids absurd estimates (0% from 0 of 5).
  • Nuisance parameters are integrated out; hierarchical models share information between groups.
  • Priors act as regularisation: a Gaussian prior gives ridge regression, a Laplace prior gives the lasso (MAP estimates).
  • Predictions include parameter uncertainty (posterior predictive).

Limitations

  • Subjectivity: with weak data, conclusions can depend heavily on the prior, and a wrong confident prior gives confidently wrong answers (the orange curve above at small n).
  • "Non-informative" priors are not unique: flat on θ is not flat on log θ, and improper priors can give improper posteriors.
  • Computation: beyond conjugate models the evidence m(x) is an intractable integral, so MCMC or variational methods are needed.
  • Bayes factors stay sensitive to the prior even with large n (Lindley's paradox).
  • The prior cannot rescue a wrong likelihood (model misspecification, ignored dependence).
  • Eliciting priors in many dimensions is hard.

Influence on statistical conclusions: good practice

  • Report the prior and the reason for choosing it.
  • Run a sensitivity analysis, as in the chart above: if the conclusion changes across reasonable priors, the data are not strong enough to decide it.
  • Check the prior with a prior predictive simulation: does it generate plausible data?
  • For rare events (Example 1), invest in a good estimate of the base rate. It matters more than the last percent of sensitivity.

Exact variance of the mean of an AR(1) sequence

function varMeanAR1(n, rho) {           // unit marginal variance
  let s = n;
  for (let k = 1; k < n; k++) s += 2 * (n - k) * Math.pow(rho, k);
  return s / (n * n);                   // = 1/n when rho = 0
}

Conclusions

  1. Four modes, four questions. Almost sure convergence is about each path, convergence in probability about each time n, L² about the average squared size of the error, and convergence in distribution only about the shape of the law. a.s. and L² each imply P, which implies d; none of the reverse implications holds in general.
  2. LLN. X̄ₙ → μ. The weak law (in probability) follows from Var(X̄ₙ) = σ²/n and Chebyshev, so it is really an L² result. The strong law (a.s.) says the whole path converges, which justifies long-run frequencies, consistency and Monte Carlo.
  3. CLT. √n(X̄ₙ − μ)/σ →d N(0,1). It holds only in distribution, which is all inference needs: tests, p-values, confidence intervals, asymptotic normality of the MLE.
  4. √n. Independence (or just zero correlation) makes variances add: Var(Sₙ) = nσ², so typical errors grow like √n and averages shrink like 1/√n. √n is the unique scaling with a non-degenerate limit. Positive dependence enlarges the constant (n_eff < n), perfect dependence removes the benefit of averaging, and infinite variance changes the rate.
  5. Bayes. Conditional probability lets us reverse the direction of conditioning: posterior ∝ likelihood × prior. The prior carries what we knew, the likelihood what the data say, and the posterior combines them coherently and can be updated as new data arrive.
  6. The prior matters most when data are scarce or the event is rare. As n grows the posterior concentrates at rate 1/√n around the truth, and Bayesian and frequentist answers meet. Transparency and sensitivity analysis keep the prior's influence honest.
