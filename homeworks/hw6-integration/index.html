Riemann and Lebesgue integration

Two ways to measure the area under a curve: slice the domain (Riemann) or slice the range and measure preimages (Lebesgue). Both are implemented here, run on nine functions, and compared on accuracy, convergence and cost.

01

Compare the two approaches in terms of accuracy, convergence and computational efficiency. 02

Two definitions of the integral

Riemann: partition the domain

Split [a, b] into n subintervals of width Δx = (b − a)/n, choose a tag ξᵢ in each one, and add up the rectangles. The function is Riemann-integrable when every choice of tags gives the same limit, which is equivalent to the upper sum U (sup on each piece) and the lower sum L (inf on each piece) squeezing together.

Rₙ(f) = Σᵢ f(ξᵢ) · Δx ∫ₐᵇ f dx = lim Rₙ(f) (n → ∞) Uₙ = Σᵢ supᵢ f · Δx, Lₙ = Σᵢ infᵢ f · Δx, integrable ⇔ Uₙ − Lₙ → 0

Lebesgue: partition the range

Split the values 0 = y₀ < y₁ < … < yₙ into levels. The set of points where f lands in a level, Eⱼ = f⁻¹([yⱼ, yⱼ₊₁)), is the preimage of that level, and m(Eⱼ) is its measure (its total length). This gives a simple function that approximates f from below. Summing the slabs instead of the columns gives the equivalent layer-cake formula, which is what we implement.

Lₙ(f) = Σⱼ yⱼ · m(Eⱼ), Eⱼ = { x : yⱼ ≤ f(x) < yⱼ₊₁ } ∫ f dm = ∫₀^∞ m({ x : f(x) > t }) dt (layer-cake formula, f ≥ 0)

The function t ↦ m({f > t}) is the distribution function of f. It is always non-increasing, and its shape, not the shape of f, decides how well the Lebesgue sums converge. For example, sin x on [0, π] has m({sin > t}) = π − 2 arcsin t, which has an infinite slope at t = 1 because sin is flat at its maximum.

The theorems we test

  • Lebesgue's criterion. A bounded function on [a, b] is Riemann-integrable if and only if its set of discontinuities has measure zero. f₃, f₄, f₆ qualify (one bad point), Thomae qualifies (discontinuous on the countable set ℚ), Dirichlet does not (discontinuous everywhere).
  • Agreement. If f is Riemann-integrable on [a, b], it is Lebesgue-integrable and the two integrals are equal. So on f₁–f₄, f₆, f₇ and T both numerical schemes must converge to the same number.
  • Monotone convergence. For f ≥ 0, if 0 ≤ fₖ ↑ f then ∫ fₖ ↑ ∫ f. Applied to the truncations min(f, H) as H → ∞, it lets the Lebesgue integral handle the unbounded f₅ directly: ∫₀¹ 1/√x dx = 2, with no "improper" limit needed in the definition.
  • Countable sets have measure zero. ℚ ∩ [0, 1] can be listed q₁, q₂, …; covering qₖ with an interval of length ε/2ᵏ covers ℚ with total length ε. Hence ∫ Dirichlet = 1 · m(ℚ ∩ [0,1]) = 0.

The algorithms

Five schemes are compared. All take a number of pieces n: subintervals for Riemann, levels for Lebesgue.

SchemeWhat it partitionsFormulaNeeds

Riemann midpointdomainΣ f(a + (i+½)Δx) Δxn values of f
Lebesgue lowerrangeΣ Δt · m({f ≥ jΔt}) (= Σ yⱼ m(Eⱼ))n preimage measures
Lebesgue midpointrangeΣ Δt · m({f > (j−½)Δt})n preimage measures
Lebesgue sampledrangesame, with m estimated from N sorted samples of fN values of f + a sort

The levels run from 0 to the maximum H of f, so Δt = H/n. For the unbounded f₅ we integrate min(f, H) with H = √n, so the levels go higher as n grows. That is the monotone convergence theorem turned into an algorithm.

The hard part of Lebesgue is the measure of a preimage. Two ways to get it:

  • Analytic preimage: solve f(x) > t by hand. For example {x² > t} = (√t, 1], length 1 − √t. For sin x / x, which is decreasing on [0, π], the preimage is [0, xₜ) and xₜ is found by bisection. Exact, but needs the inverse of f, which a general method does not have.
  • Sampled preimage: evaluate f on a fine grid of N = 2¹⁷ points, sort the values once, then count how many lie above each level with a binary search. Generic, but every measure is now "number of grid points × grid width". The method is secretly built on a fine Riemann grid, and it can never be more accurate than that grid.
// Riemann: slice the domain
function riemann(F, n, tag) {               // tag = 0 (left) or 0.5 (midpoint)
  const h = (F.b - F.a) / n;
  let s = 0;
  for (let i = 0; i < n; i++) s += F.f(F.a + (i + tag) * h);
  return s * h;
}

// Lebesgue: slice the range, add up  Δt · m({ f > t })
function lebesgue(F, n, kind, measure) {    // measure(t, ge) = m({f > t}) or m({f ≥ t})
  const H  = F.unbounded ? Math.sqrt(n) : F.max;   // truncation min(f, H)
  const dt = H / n;
  let s = 0;
  for (let j = 1; j <= n; j++) {
    s += kind === "lower" ? measure(j * dt, true)     // classic lower simple function
                          : measure((j - 0.5) * dt, false);
  }
  return s * dt;
}

// Sampled preimage measure: sort N samples once, then binary-search each level
function sampler(F, N) {
  const h = (F.b - F.a) / N, ys = new Float64Array(N);
  for (let i = 0; i < N; i++) ys[i] = F.f(F.a + (i + 0.5) * h);
  ys.sort();
  return (t, ge) => (N - firstIndex(ys, t, ge)) * h;    // points above t × grid width
}

Pathological functions: where the two definitions part ways

Dirichlet function

Every subinterval contains rationals and irrationals, so sup = 1 and inf = 0 on each piece: Uₙ = 1 and Lₙ = 0 for every n. The tagged sum depends on the tags, so there is no Riemann limit. Below, "irrational tags" are ξᵢ = (i + ½)/n + √2/(4n), which are irrational because √2 is; the page tracks them symbolically as (rational part, coefficient of √2), since a computer cannot store an irrational number.

Lebesgue has no difficulty: for 0 < t < 1 the preimage {f > t} is ℚ ∩ [0, 1], a countable set of measure 0, so the layer-cake integral is exactly 0.

Why a computer cannot even see the problem

Every finite floating-point number is m · 2ᵉ, a fraction with a power-of-two denominator. So a naive isRational(x) must return true for every input, and any numerical method returns 1 for Dirichlet. Pick a number to see how it is really stored:

Thomae's function

Thomae is discontinuous at every rational but continuous at every irrational. The discontinuities form a countable set, so by Lebesgue's criterion it is Riemann-integrable. Upper sums go to 0: in a short interval every fraction has a large denominator q, so sup f = 1/q is small. Lower sums are 0. Lebesgue: for t > 0 the set {f > t} contains only fractions with q < 1/t, a finite set of measure 0, so the integral is 0.

09

Conclusions

  • Same limit for every Riemann-integrable function. On sin x, x², the step functions, |x − ½|, sin x / x and Thomae, all schemes converge to the exact value, as the agreement theorem predicts. The differences are only in how fast.
  • Riemann accuracy depends on the smoothness of f in x. Midpoint sums converge like n⁻² for smooth f (sin x, x², sin x / x), left sums like n⁻¹. The exception is when f(a) = f(b), as for sin x and |x − ½|: then the left sum equals the trapezoidal rule and also reaches order 2. A jump spoils every Riemann scheme back to n⁻¹, an error of about jump × Δx / 2 whenever the jump falls inside a piece. A corner like |x − ½| costs nothing, since the function stays continuous.
  • Lebesgue accuracy depends on the distribution function m({f > t}), not on f. Functions that take few values are easy for Lebesgue: f₆ is exact for every n, and f₃ is exact whenever a level lands on the value 1 (n a multiple of 3), otherwise its error is of order Δt. |x − ½| has the straight-line distribution function 1 − 2t, so midpoint levels are exact. Smooth functions can be harder: sin is flat at its top and x² flat at its bottom, which gives their distribution functions an infinite slope and lowers the midpoint-level order from 2 to about 1.5.
  • Unbounded functions behave differently. For 1/√x the left Riemann sum is undefined (f(0) = ∞), and the proper Riemann integral does not exist, only the improper limit. Lebesgue handles it directly by truncating at height H and using monotone convergence: the measure m({f > t}) = 1/t² is exact, and the only error is the cut-off tail ∫_H^∞ t⁻² dt = 1/H. With H = √n both approaches converge like n^(−½).
  • Efficiency depends on the function, but in general favours Riemann. On smooth functions, midpoint Riemann reaches an error of 10⁻⁶ with 4–8 times fewer pieces than midpoint Lebesgue, and for sin x / x each Lebesgue level costs a 60-step bisection. On step functions the roles reverse: Lebesgue is exact with a handful of levels, while Riemann needs about a million subintervals. But Lebesgue's speed relies on knowing the preimages. A general method has to sample f on a grid and sort the values, which costs more than the Riemann sum it is built on, and its error stops at the grid's own error (visible for |x − ½|).
  • Pathological functions show where Lebesgue wins in theory. Dirichlet has no Riemann integral (U = 1, L = 0 forever) but a clean Lebesgue integral of 0. Thomae is integrable in both senses, with value 0. Neither can be computed by sampling, because floating-point numbers are all rational: Dirichlet always reads as 1. These cases are settled by the measure theory, not by the numerics.
