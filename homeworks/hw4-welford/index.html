Homework 4 · Statistical inference

Welford & sampling statistics

Mean and variance computed one observation at a time, then used to see how sample statistics estimate the true μ and σ² as hackers attack more and more systems.

01

Assignment

Ex. 1 – Welford's recurrence formulas. Derive Welford's recurrences for the sum of squares (SS) and the variance, following the same approach as Knuth's recurrence for the mean, and write the code (core logic ≈ 3 lines).

Ex. 2 – Sampling mean and variance. Each penetration attempt gets a score in 0 … 10 from a fixed distribution with mean μ and variance σ². m hackers each attack n systems, giving one trajectory of n scores each. Using Welford, compute every hacker's sample mean and variance, average them across hackers, compare with μ and σ², draw conclusions for inferential statistics, and repeat for different n to see how the variability of the estimates changes.

02

Ex. 1 · Deriving the recurrences

Knuth's recurrence for the mean

Writing the mean of the first n observations in terms of the mean of the first n − 1:

x̄ₙ = (1/n) Σᵢ₌₁ⁿ xᵢ = [(n − 1) x̄ₙ₋₁ + xₙ] / n x̄ₙ = x̄ₙ₋₁ + (xₙ − x̄ₙ₋₁) / n

The new mean is the old mean moved a fraction 1/n of the way toward the new observation. Call that distance δ = xₙ − x̄ₙ₋₁, so x̄ₙ = x̄ₙ₋₁ + δ/n.

Sum of squares

We want the same kind of update for SSₙ = Σᵢ₌₁ⁿ (xᵢ − x̄ₙ)². Using the identity SSₙ = Σ xᵢ² − n x̄ₙ², the difference between consecutive steps is

SSₙ − SSₙ₋₁ = xₙ² − n x̄ₙ² + (n − 1) x̄ₙ₋₁²

Write everything in terms of a = x̄ₙ₋₁ and δ, with xₙ = a + δ and x̄ₙ = a + δ/n:

xₙ² = a² + 2aδ + δ² n x̄ₙ² = n a² + 2aδ + δ²/n (n − 1) x̄ₙ₋₁² = (n − 1) a² SSₙ − SSₙ₋₁ = a² + 2aδ + δ² − n a² − 2aδ − δ²/n + (n − 1) a² = δ² (1 − 1/n) = δ · δ(n − 1)/n

Since xₙ − x̄ₙ = a + δ − a − δ/n = δ(n − 1)/n, the second factor is exactly the distance of the new point from the new mean. This gives Welford's recurrence:

SSₙ = SSₙ₋₁ + (xₙ − x̄ₙ₋₁)(xₙ − x̄ₙ) SS₁ = 0

Variance

The sample (unbiased) variance is s²ₙ = SSₙ / (n − 1), and the population form is SSₙ / n. Dividing the SS recurrence by n − 1 gives a direct update for the variance:

s²ₙ = SSₙ₋₁/(n − 1) + δ²/n s²ₙ = ((n − 2)/(n − 1)) · s²ₙ₋₁ + (xₙ − x̄ₙ₋₁)² / n (n ≥ 2)

Unlike the textbook formula Σx² − n x̄², these updates never subtract two large, nearly equal numbers, so they stay numerically stable. They also need only O(1) memory: no past observations are stored, which suits streaming data such as live security logs.

03

Ex. 1 · Code

The core logic is three lines, one per recurrence:

class Welford {
  constructor() { this.n = 0; this.mean = 0; this.ss = 0; }

  add(x) {
    this.n++;
    const delta = x - this.mean;        // xₙ − x̄ₙ₋₁
    this.mean  += delta / this.n;       // Knuth:   x̄ₙ = x̄ₙ₋₁ + δ/n
    this.ss    += delta * (x - this.mean); // Welford: SSₙ = SSₙ₋₁ + δ(xₙ − x̄ₙ)
  }

  get variance()           { return this.n > 1 ? this.ss / (this.n - 1) : 0; } // s²
  get populationVariance() { return this.n > 0 ? this.ss / this.n : 0; }
}

Check it: Welford vs. the textbook formula

Enter numbers separated by commas or spaces. Adding a large offset (e.g. 1e9) shows the textbook formula Σx² − n·x̄² losing precision while Welford stays exact.

Ex. 2 · The score distribution

Each penetration attempt gets an integer score X ∈ {0, …, 10}. The default is a Binomial(10, p) distribution, read as ten independent security checks, each passed with probability p. This models a typical hacker who usually gets part of the way in. Two other distributions are available for comparison. μ and σ² are computed exactly from the probability table:

μ = Σ k·P(X = k) σ² = Σ (k − μ)²·P(X = k)

Ex. 2 · m hackers × n systems

Every hacker produces a trajectory of n scores. A separate Welford accumulator per hacker gives that hacker's sample mean x̄ⱼ and sample variance s²ⱼ, and we then average these across the m hackers.

07

Conclusions

What the comparisons show

  • The average of the sample means matches μ for every n. A single hacker's x̄ can be far from μ, but there is no systematic error: the sample mean is an unbiased estimator, E[x̄] = μ.
  • The average of the sample variances matches σ² when we divide by n − 1. Dividing by n instead (the "biased" column) underestimates σ² by the factor (n − 1)/n, which is very visible for small n. This is why the sample variance uses n − 1 (Bessel's correction): x̄ is fitted to the same data, which uses up one degree of freedom.
  • Individual estimates fluctuate around the truth. The histograms show the sampling distributions of x̄ and s². The distribution of x̄ is bell-shaped even though the scores are discrete and bounded, as the Central Limit Theorem predicts.

Why this matters for inference

In practice we observe one sample and never see μ or σ². These results justify using x̄ and s² as estimates of them. Knowing that SD(x̄) = σ/√n, estimated by s/√n (the standard error), gives confidence intervals such as x̄ ± 1.96·s/√n and allows hypothesis tests, for example whether one hacker is significantly better than average or whether a system's mean score has changed. Welford's method lets these quantities be updated live, one attempt at a time, without storing the data.

Effect of increasing n

As each hacker attacks more systems, both estimators concentrate around the true values (Law of Large Numbers). Their spread shrinks like 1/√n: four times as many systems halve the standard deviation of x̄, and the same holds asymptotically for s². The averages across hackers stay at μ and σ² for every n, because n affects the precision of an estimate, not its bias. The simulated spreads in the table track the theoretical formulas closely.
